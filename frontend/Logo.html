Conseils d'utilisation

- Pour le web : exporte en SVG (scalable). Pour impression : exporter en PDF ou PNG 300 DPI.
- Palette suggérée : teal (#0ea5a4), corail (#ef4444), bleu foncé (#0f172a).
- Police suggestion : Roboto / Inter pour corps, et une cursive légère pour version « Eyango » si tu veux un style mode.
